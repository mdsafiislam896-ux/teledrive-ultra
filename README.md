## 🚀 লোকালি চালু করার নিয়ম (Windows)

১. প্রজেক্ট ফোল্ডারে যান:
   ```powershell
   cd C:\Users\mdsaf\.gemini\antigravity\scratch\teledrive-ultra
   ```
২. `start.bat` ফাইলে ডাবল-ক্লিক করুন (অথবা টার্মিনালে `py serve.py` লিখুন)।
৩. সাথে সাথে আপনার ডিফল্ট ব্রাউজারে `http://localhost:8080` ওপেন হয়ে যাবে!
৪. ডিফল্ট পিন দিন: `1234` (রিয়েল ড্রাইভ) অথবা `9999` (প্যানিক ডিকয় মোড)।

## 🌐 আপনার ডোমেনে সম্পূর্ণ বিনামূল্যে (100% Free) লাইভ করার উপায়

আপনার কাছে ডোমেন আছে এবং কোনো সার্ভার খরচ ছাড়াই এটি ক্লাউডে হোস্ট করতে পারেন:

### Cloudflare Pages দিয়ে ২ মিনিটে সেটআপ:
1. [Cloudflare Dashboard](https://dash.cloudflare.com/)-এ লগইন করুন (ফ্রি অ্যাকাউন্ট)।
2. **Workers & Pages** > **Create application** > **Pages**-এ যান।
3. **Upload assets** অপশন বেছে নিয়ে `teledrive-ultra` ফোল্ডারের ফাইলগুলো ড্র্যাগ অ্যান্ড ড্রপ করে আপলোড করে দিন।
4. ডিপ্লয় হওয়ার পর **Custom Domains** ট্যাবে গিয়ে আপনার ডোমেনটি (যেমন: `drive.yourdomain.com`) অ্যাড করে দিন।
5. ব্যস! ক্লাউডফ্লেয়ার স্বয়ংক্রিয়ভাবে ফ্রি SSL সার্টিফিকেট যুক্ত করে আপনার ডোমেনে টেলিড্রাইভ আল্ট্রা চালু করে দেবে।

* **iOS (Safari):** Safari-তে শেয়ার আইকনে ট্যাপ করে **"Add to Home Screen"** সিলেক্ট করুন।
